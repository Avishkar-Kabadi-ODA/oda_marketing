+----------------------------------------------------------------------------------------------------------------------+
| 1. ROLES & PERMISSION ARCHITECTURE                                                                                   |
+----------------------------------------------------------------------------------------------------------------------+

  [ Custom App Role ] : Marketing Lead (Has Desk Access, Manages Calendars, Options, Settings & Dashboard)
  [ Standard Roles  ] : Desk User / Employee (Standard Frappe users with Desk access)
  
  [ Document-Level Dynamic Role Resolution ] (Computed at runtime per deliverable):
    * If session.user == doc.assigned_to        ==> Content Writer (Can draft, edit Due Date, run Writer Copilot)
    * If session.user == doc.reviewer_technical ==> Technical Reviewer (Can review, add feedback, run Reviewer Copilot)
    * If session.user == Marketing Lead / Admin ==> Marketing Lead (Oversees, issues briefs, publishes)
    * Self-Review Prevention                    ==> If a Lead is in assigned_to, they act strictly as a Writer on that doc.

+----------------------------------------------------------------------------------------------------------------------+
| 3. AUTOMATED BACKGROUND JOBS, REMINDERS & SLA MONITORING                                                             |
+----------------------------------------------------------------------------------------------------------------------+

  +------------------------------------------------------------------------------------------------------------------+
  | DAILY CRON SCHEDULER: `oda_marketing.api.daily_sla_check_and_reminders`                                          |
  +------------------------------------------------------------------------------------------------------------------+
         |
         +---> 1. SLA Due Date Reminder (`reminder_1_days_before`):
         |        - Trigger: Today == due_date - reminder_days (e.g. 3 days before due date).
         |        - State  : Active items in [Briefed, In Progress, In Revision].
         |        - Action : Sends "Marketing Due Date Reminder" email template to assigned writer.
         |
         +---> 2. Overdue Auto-Escalation & Late Flag:
         |        - Trigger: Today > due_date AND state NOT IN [Approved, Published].
         |        - Action : Sets `doc.risk_flag` = "Late" (if enable_auto_overdue_flag is active).
         |        - Action : Sends "Marketing Overdue Alert" email to Marketing Lead & Writer.
         |
         +---> 3. Auto-Overdue Status Sync:
                  - Syncs deliverable health metrics directly into Marketing Dashboard Executive KPI Cards.


+----------------------------------------------------------------------------------------------------------------------+
| 4. AI COPILOT 2-STAGE SUBAGENT EXECUTION PIPELINE                                                                    |
+----------------------------------------------------------------------------------------------------------------------+

           [ Content Item Metadata (Title, Format, Domain, Brief, Reviewer Instructions) ]
                                                   |
                                                   v
   +-----------------------------------------------------------------------------------------------+
   | STAGE 1: PROMPT GENERATOR SUBAGENT (prompt_subagent.py)                                       |
   | - Pulls `subagent_meta_prompt` template from Marketing Settings                               |
   | - Injects deliverable-specific criteria, format guidelines, and domain requirements           |
   | - Calls LLM API endpoint:                                                                     |
   |     * Headers: {"Authorization": "Bearer <key>", "api-key": "<key>"}                          |
   |     * Providers supported: NVIDIA NIM, OpenAI, Anthropic, Azure APIM, Mock Heuristic          |
   | - Generates customized, production-grade System Prompt for Evaluator Agent                    |
   | - (Auto-fallback to deterministic prompt template on network/timeout exception)               |
   +-----------------------------------------------------------------------------------------------+
                                                   |
                                                   v  (Tailored System Prompt)
   +-----------------------------------------------------------------------------------------------+
   | STAGE 2: PRIMARY EVALUATOR AGENT (evaluator_agent.py)                                         |
   | - Consolidates working notes (`doc.notes`) and primary draft text (`doc.content_file_1`)       |
   | - Applies Stage 1 System Prompt with temperature 0.2                                          |
   | - Outputs structured JSON schema:                                                             |
   |     {                                                                                         |
   |       "overall_score": 92,                                                                    |
   |       "technical_accuracy_score": 90,                                                         |
   |       "clarity_score": 95,                                                                    |
   |       "structure_score": 90,                                                                  |
   |       "verdict": "PASS",                                                                      |
   |       "key_strengths": ["Clear multi-cloud architecture...", "Proper terminology..."],        |
   |       "critical_flaws": [],                                                                   |
   |       "actionable_feedback": "Detailed markdown recommendations for Content Writer..."       |
   |     }                                                                                         |
   | - Writes results to `tabContent Item`:                                                        |
   |     * `ai_score` = 92                                                                         |
   |     * `ai_review_status` = 'Completed'                                                        |
   |     * `ai_copilot_feedback` = Formatted Markdown Summary                                      |
   +-----------------------------------------------------------------------------------------------+
                                                   |
                                                   v
     [ Informational Quality Feedback Displayed on Deliverable Form View in Frappe Desk ]
