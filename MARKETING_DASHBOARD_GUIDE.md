# Marketing Operations Dashboard Guide

## 1. Executive Summary & Purpose

The **Marketing Operations Dashboard** (`/app/marketing-dashboard`) provides real-time visibility, operational analytics, and SLA oversight across all marketing content deliverables in **Optimum Data Analytics (ODA)**. It aggregates data from the `Content Item` and `Content Calendar` DocTypes, enabling Marketing Leads and Executives to monitor production velocity, track publishing deadlines, balance format mixes, and ensure editorial quality.

* **Route:** `/app/marketing-dashboard`
* **Access Control:** Restricted strictly to **`Marketing Lead`** and **`System Manager`** roles. Non-leads attempting to access the page are redirected to the Content Item list with a permission alert.

---

## 2. Interactive Analytics Filter Toolbar

The top filter card allows dynamic multi-dimensional slicing across the entire content database:

| Filter Name | Element | Behavior & Filtering Logic |
| :--- | :--- | :--- |
| **Content Calendar** | Select dropdown | Filters deliverables assigned to a specific marketing campaign/calendar (e.g., `2026 Marketing Calendar`) or `All Calendars`. |
| **Year** | Select dropdown | Filters deliverables by planned publication year (`2025`, `2026`, `2027`, `All Years`). |
| **Month / Period** | Select dropdown | Filters by planned publication month (January–December, or `Full Year`). |
| **Format** | Select dropdown | Filters by deliverable format (`Blog`, `Poll`, `Carousel`, `Flowchart`, etc.). |
| **Industry Domain** | Select dropdown | Filters by target domain (`HCLS`, `Fintech`, `Pharma Supply Chain`, `Cross-domain`, etc.). |
| **Risk Status** | Select dropdown | Filters by SLA risk level (`On track`, `At risk`, `Late`). |
| **Reset Filters** | Button | Instantly resets all controls back to default full-scope view (`All Calendars`, Current Year, Full Year, All Formats, All Domains, All Risk Levels). |

All KPI cards, charts, and summary tags update dynamically in real time when any filter selection changes.

## 3. Real-Time KPI Cards Matrix

The KPI grid summarizes deliverable volume, state progression, and quality metrics. **Each card is interactive**—clicking a KPI card immediately navigates to the filtered Content Item list view.

| KPI Card | Color Theme | Indicator / Metric | Click Action |
| :--- | :--- | :--- | :--- |
| **Total Deliverables** | Indigo (`#4F46E5`) | Total count of content items within the selected filter scope. | Opens full Content Item list. |
| **Planned** | Slate (`#64748B`) | Items in initial conceptual/stub phase not yet briefed to writers. | Opens List with `workflow_state: Planned`. |
| **Briefed** | Blue (`#2563EB`) | Items where brief is issued; waiting for writer to accept & start work. | Opens List with `workflow_state: Briefed`. |
| **In Progress** | Orange (`#EA580C`) | Items undergoing active drafting and research by assigned writers. | Opens List with `workflow_state: In Progress`. |
| **In Review** | Yellow (`#CA8A04`) | Drafts submitted by writer awaiting review from assigned Technical Reviewer. | Opens List with `workflow_state: In Review`. |
| **In Revision** | Red (`#DC2626`) | Deliverables where reviewer requested changes; writer adjusting copy. | Opens List with `workflow_state: In Revision`. |
| **Approved** | Cyan (`#0891B2`) | Reviewer approved deliverables ready for staging/publishing. | Opens List with `workflow_state: Approved`. |
| **Published** | Emerald (`#059669`) | Live assets published to web, social, or client portals with live URL. | Opens List with `workflow_state: Published`. |
| **Late Risk** | Crimson (`#BE123C`) | Deliverables past their SLA due date that are not yet approved/published. | Opens List with `risk_flag: Late`. |
| **AI Quality Score** | Purple (`#7E22CE`) | Average evaluation score (%) generated by the 2-stage AI Copilot engine. | Informational average score badge. |

## 4. Visual Analytics & Chart Breakdown

```
+---------------------------------------------------+---------------------------------------------------+
|  1. Workflow Pipeline Funnel (Donut + Pills)      |  2. Monthly Publication Cadence (Bar Chart)       |
|  Distribution across 7 lifecycle workflow states   |  Target publication volume across calendar months |
+---------------------------------------------------+---------------------------------------------------+
|  3. Content Format Distribution (Bar Chart)       |  4. Industry Domain Breakdown (Bar Chart)         |
|  Format balance (Blog, Poll, Carousel, Flowchart) |  Audience coverage across target vertical domains |
+---------------------------------------------------+---------------------------------------------------+
```

### Chart 1: Workflow Pipeline Funnel
* **Chart Type:** Donut Chart with Responsive Interactive Legend Pills
* **Color Palette:** 
  - Planned (`#64748B`) | Briefed (`#2563EB`) | In Progress (`#EA580C`) | In Review (`#CA8A04`)
  - In Revision (`#DC2626`) | Approved (`#0891B2`) | Published (`#059669`)
* **What it Explains:** 
  - Visualizes where deliverables currently sit across the 7-stage workflow pipeline.
  - Highlights operational bottlenecks (e.g., a bulge in `In Review` indicates a review backlog; a bulge in `In Revision` indicates draft alignment issues).
* **Responsive Legend Feature:**
  - Standard SVG legends can clip or overflow on smaller viewports. The dashboard replaces fixed SVG legends with a dynamic Flexbox pill container.
  - Each pill displays a colored status dot, workflow state name, exact deliverable count, and percentage share.
  - **Interactivity:** Clicking any legend pill instantly routes to the List View filtered by that workflow state.

---

### Chart 2: Monthly Publication Cadence
* **Chart Type:** Bar Chart
* **Color:** Indigo (`#6366F1`)
* **What it Explains:**
  - Displays deliverable volume mapped across the 12 calendar months (Jan–Dec) based on `planned_publish_date`.
  - Enables marketing managers to spot uneven publication schedules, identify quiet months, and avoid content clustering before major campaigns or product releases.

---

### Chart 3: Content Format Distribution
* **Chart Type:** Bar Chart
* **Color:** Violet (`#8B5CF6`)
* **What it Explains:**
  - Measures the diversity of content formats currently planned or published (`Blog`, `Poll`, `Carousel`, `Flowchart`, etc.).
  - Helps marketing teams maintain a healthy omnichannel content mix between long-form thought leadership (Blogs, Whitepapers) and high-engagement visual assets (Polls, Carousels).

---

### Chart 4: Industry Domain Breakdown
* **Chart Type:** Bar Chart
* **Color:** Sky Blue (`#0EA5E9`)
* **What it Explains:**
  - Visualizes deliverable allocation across target business verticals and industries (`HCLS`, `Fintech`, `Pharma Supply Chain`, `Agriculture`, `Cross-domain`).
  - Ensures strategic balance so no key market segment or target audience is neglected.

## 5. Technical Implementation & Data Flow

```
[ User Filters UI (Dropdowns) ]
            |
            v (frappe.call)
[ Python Whitelisted Endpoint: get_dashboard_metrics ]
  - Parameterized SQL query on `tabContent Item`
  - Calculates status counts, SLA overdue counts, AI average scores
  - Aggregates monthly trends, format breakdown, and domain breakdown
            |
            v (JSON Response)
[ MarketingOperationsDashboard JS Class ]
  - Populates dynamic dropdown options on first load
  - Updates KPI counter DOM elements
  - Renders Frappe Charts with responsive container resizing
  - Builds interactive flex legend pills for the Funnel Donut Chart
```

* **Window Resize Handling:** A debounced resize listener (`resize.marketing_dashboard`) automatically re-renders chart canvases when the browser window or sidebar expands/collapses.
